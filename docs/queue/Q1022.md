# Rewrite tech-docs-layers to bootstrap or sweep

[`decisions.md`](../decisions.md) settles that this skill lost a competition
rather than never entering one: in `github-actions-gateway`, which holds 433 of
the 654 measured docs occasions and is the only checkout here with a docs
framework, the loaded `CLAUDE.md` reaches this skill's moment three times and
routes all three to two local pages. The skill is named only in that repo's
`docs/development/skills.md`, which nothing loads.

The case it has never been scoped to is the other one: **a repo with a `docs/`
tree and no docs conventions of its own**. Four of the six checkouts here are
that — `claude-bouncer`, `claude-pr-sentinel`, `claude-spill-guard` and
`claude-ground-truth` carry no `documentation-standards.md`, against
`github-actions-gateway` and `kube-headroom` which do. Those four hold 221 of
the 654 occasion sessions.

Framework presence, read from the checkouts: `github-actions-gateway` has
`mkdocs.yml` over 428 pages. `claude-bouncer` (67 pages), `claude-spill-guard`

that already declined the skill.

## The shape, settled

**Two modes, one moment.** The skill fires on a docs edit as it does today. It
then branches on what the repo has:

- **No docs conventions of its own** — write the repo one. A change-type to
  docs mapping, a standards page, and a proposal for the gates that carry the
  sweep. This is what `github-actions-gateway` did for itself, and it is the
  half that produces a local page instead of competing with one.
- **A conventions doc already** — defer to it, and run the sweep. The local
  page wins on everything it covers, which is the finding this row comes from.

Chosen by the maintainer on 2026-09-24 over three alternatives, recorded
because the reasons transfer. **Narrowing to survey-and-sweep** answers the
same question with less and may still fire zero, since the description was
never the lever. **Bootstrap alone**, as a renamed skill, has the cleanest
moment and a ceiling of four firings ever across the checkouts here. **Reopening
retirement** forecloses the framework-less case before it has been tried once.

The two-mode shape is the largest rewrite of the four, and its bootstrap half
is modelled on a single success. Both costs were stated when it was chosen.

## What Q1023 measured

The shape rested on one held claim: **the six layers' content is ordinary
technical-writing knowledge a model already carries, and what the body adds is
the instruction to survey first and sweep after**, 28.1% of it. Q1023 tested it
on 2026-11-01 with one task, one run per arm, in `claude-pr-sentinel`, and the
claim did not survive. The control arm, with the body blocked but the
description still in its skill listing, did both the terminology sweep and the
link sweep completely. That scopes the result to the body. It does not show the
model sweeps with no trace of the skill. Where the skilled arm did
more, it was terminology, layer 1's subject: it added the new name to two
sentences that described the feature without naming it, and caught two more
bare back-references. Layers 3 to 6 were not exercised. The run, its controls and its caveats are in
[`decisions.md`](../decisions.md#measured-the-sweep-was-not-the-difference-terminology-was).

So a rewrite cut down to survey-and-sweep would keep the part that made no
difference here and drop the layer that the only extra work fell under. On this
evidence, keep the layer 1 exposition. The evidence says nothing either way
about layers 3 to 6, so don't argue for or against them by symmetry with layer
1. The probe does not bear on the bootstrap half.

**Ask (answered):** which shape, answered above on 2026-09-24. The maintainer
also directed that the assumption be measured before the rewrite rather than
after, which Q1023 did; its row was deleted when it completed.

The retirement question stays where `decisions.md` leaves it: reopened only if
a rewrite ships against the framework-less case and still measures zero.
