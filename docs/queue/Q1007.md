# The naming line the README recommends has a hit rate of zero

The README tells an adopter to name a skill in a `CLAUDE.md`, and the sample
line it gives is keyed to a document type rather than to a moment: "a doc,
README, release note, PR body, or post that is written and needs a review
pass". The one naming line that has been measured in the wild has that shape
and does not fire.

Measured 2026-09-14 over 2,117 local transcripts under `~/.claude/projects/`,
one workstation:

| occasion | sessions | fired |
|---|---|---|
| edited a page `github-actions-gateway` publishes | 162 | **0** |
| edited a non-published `docs/` file there | 230 | 1 |
| edited 8 or more `docs/*.md` files anywhere | 65 | 2 |
| edited 3 or more `docs/*.md` files anywhere | 329 | 2 |

That repo's `CLAUDE.md` says a change under `docs/` is a change to a live web
page and to review it with `rendered-page-review`. The condition held 162
times and the skill fired on none of them. All 11 of its real calls come from
sessions that edited no Markdown at all — somebody opened a review session on
purpose, which is a moment, and the skill fired.

`tech-docs-layers` shows the same shape from the other side. It is named in no
`CLAUDE.md` on that machine, and the scope defence does not cover it: 63
sessions rewrote eight or more documentation pages in one go without reaching
for it.

So [decisions.md](../decisions.md)'s naming entry is right about the lever and
silent about its shape. A line naming a skill *at a moment somebody notices* —
opening a review, finishing a draft — fires. A line naming it *as a standing
property of a file path* reads as true, gates nothing, and is invisible at the
moment it would have to act, because nothing re-reads it when the condition
becomes true.

The work is to say so where an adopter reads it: rewrite the README's install
guidance to require a moment rather than a condition, and mark the sample line
as one shape rather than the shape. The two skill descriptions are a separate
question and not this row — the measurement says nothing about them, since a
description only decides matching once the subject is already in context.

**What would settle the wider claim:** a naming line of the moment shape,
added for one of these two skills, scored forward against the window after it
ships. That is a measurement somebody else's repo has to host, so it is out of
scope here.
