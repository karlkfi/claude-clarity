# A control built from the artifact under test checks the derivation

**Groom this as a probable duplicate before working it.** The body already
states both halves — §2's *A control drawn from inside the enumeration it is
testing cannot fail* and *A sound instrument still answers only its own
question* — and this is their conjunction rather than a new law. What is filed
here is the exhibit, because the exhibit is what the existing rules lack for
this shape: a probe that builds its own pattern set out of the subject, and a
control over that set.

**The case.** `scripts/rule-residency.py` measures which rules in a skill body
reach the output of the sessions that loaded it. Its first build keyed each rule
on word sequences unique to that rule *within the body*, and reported 43 of 93
rules unmeasurable — among them *A negative needs a positive control*, which the
same body calls the sharpest rule in it.

`--self-test` passed on that build, and could not have done otherwise. It fires
each rule's markers at that rule's own text, and the markers were extracted from
that text, so it establishes that the matcher can find a phrase where the phrase
demonstrably is. The property in doubt was different and never tested: whether a
reader applying the rule reproduces any of those phrases. The uniqueness filter
had deleted exactly the vocabulary each rule is known by, because this body
cites its own rules constantly — so the phrases a reader actually writes were
the ones systematically excluded.

What refuted it was a phrase known present in the corpus rather than in the
file: `positive control` appears 546 times across 73 of 85 reader sessions after
the load, against 45 times in 10 sessions before it. Re-keyed on each rule's
lead, that rule tops the table. Measured 2026-09-18; the instrument and the
reading are in [`docs/verify-claims-residency.md`](../verify-claims-residency.md).

**The tell, if this earns a clause rather than a close:** the control's input and
the probe's pattern have one source, so the control is a check on the derivation
and silent on whether the derived thing describes the world. Ask what the control
would report if the derivation were sound and the *choice* of what to derive were
wrong. Where the artifact under test is an index built from the subject, the
known-positive has to come from outside the derivation — not merely outside the
list, which is what the existing rule already asks for.

**Where it would land.** As a clause on §2's *A control drawn from inside the
enumeration it is testing cannot fail*, which is the rule it extends. It
competes for space in a shrink-only body with [Q274](Q274.md), which parks the
identity-shaped cross-check, and with the in-flight row on mutations needing one
direction each — three parked exhibits now converge on controls that cannot
fail, and that convergence is the argument for folding one rather than all
three. [Q1003](Q1003.md) is the pass that would create the room, and its reading
says the room is 20.6 kB.

Filed 2026-09-18, from the session that built the instrument.
