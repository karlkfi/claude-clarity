# Two lines of the residency instrument are covered by review, not a gate

`scripts/rule-residency.py` landed with three changes that answer a review
finding, and two of them nothing checks: the `# authoring repos` line every run
prints so a bare invocation says which reading it is, and the `verdict` and
`repos` keys added to `--json`. A future edit can drop either silently and
`make check` stays green.

**The gap is deliberate and was disclosed rather than papered over.** Its author
flagged both lines as untested when handing the PR back, rather than letting a
green gate imply otherwise, and the reviewer declined to demand a test and
recorded why: `scripts/test-rule-residency.sh` is deliberately corpus-free, so
it cannot exercise output that only exists when the walk has a real corpus to
segregate — and a `--help` string check is the crying-wolf shape `CLAUDE.md`
warns against, a gate that fails on rewording rather than on behaviour.

**Why it is worth a row rather than a shrug.** Those two lines are what make a
reading self-describing. The `# authoring repos` line is the only thing that
separates a flagged run from a bare one in the output itself, and the published
table in `docs/verify-claims-residency.md` is reproducible only under the
flagged invocation — measured 2026-09-18, the bare run reports 26 rules and 24%
where the flagged run reports 21 and 19%. Drop the line and a reader cannot tell
which reading they are holding, which is the defect the review finding was
about, one hop out.

**What a check would have to do.** Exercise the shipped path against a real
corpus without pinning a number that drifts — the counts move as sessions
accumulate, which is what `docs/verify-claims-residency.md` records. So the
assertion is structural: that the repos line is present and names what was
segregated, and that a `--json` record carries both keys. Whether that earns a
corpus-dependent test in a suite built to avoid one is the open question, and it
is a real trade rather than an oversight to correct.

**Measure:** whether a structural assertion can run without a corpus — a
synthetic transcript tree is the candidate, and if it is cheap the row is small.
If it needs a real corpus it is a different and larger row.

Filed 2026-09-19 from the batch retro, on the reviewer's suggestion. The
disclosure is in PR #10's review comment.
