# Measure whether the skill's value is the sweep or the layer vocabulary

[Q1022](Q1022.md) blocks on this. Every shape considered for that rewrite rests
on one claim, stated in [`decisions.md`](../decisions.md) as held rather than
checked: the six layers' content is ordinary technical-writing knowledge a
model already carries, and what the body supplies is the instruction to survey
first and sweep after — **28.1% of 11,725 bytes**, against 28.6% for layers 3–6
alone. A rewrite that keeps the layer exposition is betting against it, and a
rewrite that cuts it is betting on it. Nothing measures it today.

## The probe

Run one docs task twice against a repo with a `docs/` tree and no docs
conventions of its own, in fresh sessions: once with `tech-docs-layers`
invoked, once without. Read the difference.

**Pick the repo from the four that qualify** — `claude-bouncer`,
`claude-pr-sentinel`, `claude-spill-guard`, `claude-ground-truth` — none of
which carries a `documentation-standards.md`, measured 2026-09-24. Clone it
shallow into the session scratchpad rather than reading a checkout this session
does not control.

**Pick a task that can exercise both halves**, or the probe cannot come back
negative: one that renames a term appearing on several pages and moves a page
other pages link to. A task touching one page exercises neither the terminology
sweep nor the link sweep, and would return "no difference" for reasons that say
nothing about the skill.

## What the reading has to distinguish

Three outcomes, and they license different rewrites:

- **Sweep behaviour only** — the skilled run greps for inbound links and
  terminology after the edit and the unskilled one does not, with no other
  difference. Confirms the claim, and the rewrite cuts the layer exposition.
- **Layer vocabulary too** — the skilled run also reaches for something the
  unskilled one had available and did not use. Refutes the claim for whichever
  layer showed it, and that layer survives the cut.
- **No difference** — either the model already sweeps, which retires the
  skill's last load-bearing part, or the task could not tell. Check the task
  against the paragraph above before reading this one as a result.

## What this cannot establish

One task in one repo, run once. It informs the rewrite and does not prove the
claim, and a null result is the outcome most likely to be the probe's fault
rather than the skill's. Say which of the three came back and on what task;
do not generalise from it to the other five layers by symmetry.

**Two runs of the same task differ for reasons that have nothing to do with the
skill.** Sampling is one source and the transcript is another: the unskilled
session still loads whatever `CLAUDE.md` the chosen repo carries, and three of
the four candidates name skills in theirs. Read that file first and say what it
already instructs, or the control arm is not a control.
