# Publishing is undecided, and there is no path if the answer is yes

**Demand:** someone outside this machine asks for these skills, or the hook is
wanted on a second machine. Either one makes installability the thing that is
missing; neither has happened.

This is a local clone with no remote. The plan it was extracted under is
explicit that creating a public repository is an outward-facing act needing its
own decision, and on 2026-09-14 that decision was *not yet* — nothing is
pushing on it, so the repo stays local and this row waits for the trigger above.

**The question is not only whether.** Nothing here covers what publishing would
need: a version scheme, a release process, release notes, or a
`.claude-plugin/marketplace.json` if the distribution is a Claude Code plugin
rather than a git clone people run `install-skills.sh` against. The skills sit
under `skills/`, which is the plugin layout, so the plugin route is open and
costs a manifest — but nobody has decided it is the route.

**What reviving it would change.** While the repo stays local, the rest of this
store is private housekeeping: [Q1004](Q1004.md) is a correctness debt nobody
outside meets, and the grandfathered body in [Q1003](Q1003.md) is nobody's first
impression. If the trigger fires, three things become blocking rather than
additive — the corpus scope line has to survive outside review, that body
becomes a first impression, and the single-skill install the README now
documents becomes an instruction strangers follow.

**Ask (answered):** publish or not. The plugin-or-clone half was already
answered: the repo takes a plugin manifest beside `install.sh`, because a hook
cannot reach a machine any other way without hand-editing a settings file. The
reasoning is in [decisions.md](../decisions.md) (Q1008). That was decided for
the hook rather than for distribution, so it constrains this question without
settling it — and a local directory works as a marketplace with no remote
(measured in Q1008), so the hook ships and runs here regardless. What waits on
the trigger is other people being able to install it.
